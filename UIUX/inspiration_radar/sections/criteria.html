Defining “Worth Discovering”

Subjective creative qualities needed a structured recommendation system.

Instead of relying only on popularity, each project is evaluated through multiple signals.

Freshness

How recent or actively maintained is the project?

Momentum

Is the project currently gaining attention?

Creative Relevance

Is it related to creative coding, interaction, visual design, AI, 3D, or generative systems?

Inspiration Value

Does it contain an interesting idea, interaction, implementation, or creative mechanism?

Vibe

What creative character does the project have?
