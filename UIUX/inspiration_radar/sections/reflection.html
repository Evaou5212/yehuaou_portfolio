Reflection

Recommendation is not only a ranking problem — it is also a definition problem.

The biggest challenge was not simply making AI find projects, but first defining what “interesting,” “creative,” and “worth discovering” actually mean. Vague prompts produced technically popular repositories. Clearer criteria produced more meaningful finds.

A second takeaway: AI works better as an interpreter than as an unquestioned tastemaker. GitHub metadata provides objective signals such as freshness and popularity, while AI helps interpret creative intent and project characteristics. Combining structured data, AI interpretation, and intentionally designed criteria produced better recommendations.

The project moved from a simple GitHub trending aggregator into a more intentional creative discovery system.
