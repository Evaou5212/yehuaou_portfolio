Key Features

Six ways to discover, judge, and keep exploring.

01

Live Radar

The archive automatically discovers and refreshes GitHub projects every six hours, so the catalog stays current without requiring users to hunt through Trending.

02

AI-Assisted Curation

Each entry explains why a project may be interesting to creative users. The system interprets intent, vibe, and stealable ideas rather than simply summarizing README content.

03

Search & Filtering

Users can explore the archive through project type, technology, medium, activity, and creative characteristics — from a broad scan to a precise search without leaving the catalog.

04

More Like This

Related projects are connected so a single find can become a trail. Users can continue exploring similar ideas instead of restarting from search every time.

05

Surprise Me

For users who do not know exactly what they are looking for, Surprise Me supports serendipitous discovery as a counterpart to filters and search.

06

Share a Find

Users can submit a GitHub repository they think is worth discovering. Human finds complement automated discovery and keep the archive from becoming a closed machine-only loop.
