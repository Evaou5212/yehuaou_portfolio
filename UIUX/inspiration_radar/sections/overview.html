Built With AI / Inspiration Radar is a continuously updated discovery archive that surfaces interesting, creative, and inspiring GitHub projects for designers, creative coders, and vibe coders.

The case study is not only about the final website UI. It follows the product problem, the pivot away from trending-as-inspiration, the recommendation criteria, and an AI-assisted curation system that helps interpret creative intent rather than ranking repositories by stars alone.
