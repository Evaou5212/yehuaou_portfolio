User Flow

Rather than mapping a user's actions, this journey maps their changing mental state throughout the wake-up process. At each stage, WakePlan identifies a specific pain point and introduces a targeted intervention to gradually restore awareness, intention, and control.

User Stage User State Pain WakePlan Response
Night before “I’m afraid I’ll oversleep.” 😟 Anxiety Create a Wake Plan
Early wake “I’m still half asleep.” 😴 Low awareness Announces current time
Mid wake “Maybe I can sleep 10 more minutes.” 😵 Autopilot Plays personalized reminder
Target time “I need to get up now.” 😐 Risk of oversleeping Requires wake-up task
Fully awake “I’m ready to start my day.” 😄 Regained control Wake successful
